Profile

What I actually do all day

Most security tooling ships loud. My job is to make it accurate — writing detections that fire on real adversary behavior, tuning away the noise that trains analysts to ignore their own queue, and closing the cloud misconfigurations that make the detections necessary in the first place.

The newer half of the work is AI security. Model APIs, retrieval pipelines, and agentic services introduce attack surface that no existing rule set covers: prompt injection, model API abuse, data leakage through generated output. I map that surface to MITRE ATLAS the same way I map cloud activity to ATT&CK, then build the telemetry and detections to cover it.

Underneath both: Python automation in CI/CD, least-privilege IAM, encryption and logging baselines, and post-incident work that stops the same thing happening twice.
